# Iron Crown.IO

브라우저에서 실행되는 싱글플레이 기사 난투 게임입니다. 실제 멀티플레이 대신 AI 기사 15명과 전투합니다.

## 플레이

- 공개 주소: https://player149.github.io/
- PC: WASD 이동, 좌클릭 공격, 우클릭 막기, Shift 달리기, Space 대시
- 기술: Lv.5 E, Lv.15 R, Lv.25 Q
- 모바일: 화면의 가상 조이스틱과 전투 버튼 사용
- 테스트: L 즉시 레벨업, B 보스전 즉시 시작(Lv.10 필요)

## 구현된 시스템

- 최대 40레벨과 매 레벨 능력 선택
- 5/15/25레벨 분기 진화
- 레벨 1→40 기본 체력 100→400, 스태미나 100→200 선형 성장
- 레벨업 시 최대 체력의 15% 회복, 비전투 5초 후 초당 10% 회복
- 초당 스태미나 30 회복, 기본 공격 15·기술 25 소모
- 방어 중 이동 속도 50% 및 스태미나 회복 정지
- 방어 성공 시 방어자 5·공격자 15 추가 소모, 스태미나가 바닥나면 2초간 탈진
- 몬스터, 경험치 지대, AI 기사 전투
- 5분 주기의 3분 보스전
- 골드, 룬 뽑기, 영구 강화, Lv.5 시작권
- 최대 3회 골드 부활
- localStorage 자동 저장
- 모바일 반응형 UI와 PWA 오프라인 캐시

## 프로젝트 구조

```text
index.html              화면 마크업
css/game.css            전체 스타일과 모바일 반응형 UI
js/core.js              캔버스, 입력, 저장 데이터, 전역 게임 상태
js/entities.js          기사와 몬스터
js/combat.js            공격, 기술, 경험치, 레벨업, 진화 데이터
js/boss.js              보스전과 한 판의 생명주기
js/render.js            업데이트 루프, 월드 렌더링, HUD
js/ui.js                메뉴, 상점, 일시정지, 모바일 조작
js/main.js              시작점과 오프라인 기능 등록
sw.js                   정적 파일 오프라인 캐시
manifest.webmanifest    모바일 설치 정보
```

## 유지보수 원칙

- 밸런스 수치는 `js/combat.js`의 성장·선택지·진화 데이터에서 수정합니다.
- 캐릭터 동작은 `js/entities.js`, 보스 규칙은 `js/boss.js`에서 수정합니다.
- 새 이미지와 사운드는 `assets/` 아래에 종류별로 추가합니다.
- `main` 브랜치에 반영된 변경은 GitHub Pages로 배포됩니다.

## 현재 범위

이 버전은 서버가 없는 싱글플레이 프로토타입입니다. 실시간 PvP, 계정 서버, 결제 및 전 세계 순위는 포함하지 않습니다.
